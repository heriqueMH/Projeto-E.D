# Java - Estruturas de Dados 🧩

Projeto acadêmico de implementação de algoritmos e estruturas de dados em Java, abordando conceitos fundamentais para organização e manipulação eficiente de dados.

## ✨ Funcionalidades

- Implementação de filas
- Implementação de pilhas
- Operações básicas em listas
- Simulações de operações de inserção, remoção e consulta

## 🛠️ Tecnologias Utilizadas

- Java 17
- Estruturas de Dados

## 🚀 Como executar o projeto

git clone https://github.com/seu-usuario/java-estruturas-dados.git
cd java-estruturas-dados
